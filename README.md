# Архитектура и структура проекта 

Проект разделен на независимые слои для обеспечения удобной командной работы через репозиторий Git.

# Общая структура папок

* `.gitignore` - Технический файл-фильтр. Указывает Git, какие файлы (например, локальную базу данных, кэш Python) не нужно отправлять в общий репозиторий, чтобы не затирать локальные данные участников.
* `graphics/` — Рабочая зона дизайнера. Здесь хранятся макеты интерфейса, UI-киты, экспорт иконок, логотипы и скриншоты экранов из Figma.
* `frontend/` — Рабочая зона фронтенд-разработчика. Логика интерфейса на JavaScript, разметка HTML и визуальные стили CSS.
* `backend/` — Рабочая зона бэкенд-разработчика. Серверная логика на Python, REST API эндпоинты и база данных SQLite.

# Детализация папки backend 

* `app.py` — Главный файл запуска сервера. Инициализирует Flask-приложение, регистрирует эндпоинты API и запускает веб-сервер на локальном порту (5000) для прослушивания запросов от фронтенда. При самом первом старте автоматически вызывает инициализацию таблиц.
* `database.py` — Управление подключением. Отвечает за открытие безопасных сессий соединения с базой данных SQLite и настройку формата возвращаемых данных (в виде удобных словарей `Row`).
* `models.py` — Схемы данных и таблиц. Содержит чистые SQL-скрипты (`CREATE TABLE`) и описывает структуру сущностей MVP (Инициативы, Комментарии, Логи истории изменений).
* `routes.py` — REST API Маршрутизатор. Принимает сетевые запросы от фронтенда (GET, POST, PATCH), вызывает соответствующую логику работы с базой данных и возвращает структурированные ответы в формате JSON.
* `database.db` — Локальный файл базы данных SQLite. Создается автоматически кодом на Python при первом запуске сервера. Хранит все таблицы проекта. Благодаря `.gitignore` находится только на компьютере текущего разработчика.
* `query.sql` — Песочница SQL. Технический черновик бэкендера для написания, отладки и проверки чистых SQL-запросов перед их интеграцией в Python-код.

# Детализация папки frontend

* `index.html` — Главный каркас приложения (Single Page Application). Содержит базовую разметку и пустые контейнеры, в которые JavaScript динамически подставляет нужные экраны.
* `style.css` — Визуал и дизайн. Отвечает за шрифты, сетку (Flexbox/Grid), отступы и приглушенную цветовую гамму интерфейса по макетам из Figma.
* `js/` — Папка с модульной логикой интерфейса:
  * `api.js` — Модуль сетевых запросов. Содержит функции `fetch()` для общения с Python-сервером (отправка новых форм, получение свежего списка инициатив).
  * `render.js` — Модуль отрисовки. Принимает сырые данные (JSON) от сервера и превращает их в красивый HTML-код (генерирует карточки идей, списки комментариев, строки истории).
  * `auth.js` — Контролер доступов. Хранит текущую роль пользователя (Сотрудник / Модератор) и динамически скрывает или показывает элементы управления (например, кнопки смены статуса).
  * `app.js` — Главный диспетчер фронтенда. Слушает клики по кнопкам, открывает модальные окна, собирает данные из полей ввода и координирует совместную работу модулей `api.js` и `render.js`.
